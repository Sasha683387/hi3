# 40 метров тишины — премиум-прототип

Соло- и кооп-прототип механики «голос-инструмент» из кооп-концепта про тонущую подлодку.
(Вдохновлено формулой BOMBANANA! — кооп с асимметричной информацией, но с другим базовым циклом.)

## Механика

- Трубу чинит **голос**: чем громче — тем быстрее (**крик ≈ 17%/с**, шёпот ~2.6%/с).
- **Щиток** чинится **только шёпотом**: крик у щитка даёт искры, откат ремонта и тряску.
- Громкость шкалы **адаптивная**: твой самый громкий за последние секунды звук ≈ 100% шкалы. Если всё равно мало — подними ползунок **«Чувствительность микрофона»** (в меню и в паузе).
- Заделка системы даёт **+25 воздуха** и откачивает 20% воды.
- **Сосед** плывёт на громкий звук: кричи кусками, между криками молчи — тишина отгоняет его.
- Луз: воздух кончился, отсек затопило (вода 100%), Сосед добрался.

## Мультиплеер (2 игрока)

- Хост: **«Создать комнату»** → получить 4-буквенный код.
- Гость: **«Подключиться к другу»** → ввести код.
- Соединение P2P (WebRTC через PeerJS, без игрового сервера). Видишь аватар друга и слышешь его голос (лучше в наушниках!).
- Хост считает мир: воздух, вода, Сосед и поломки; гость отправляет голос и позицию.
- **Дуэт**: если вы оба кричите/шепчете у одной системы — ремонт идёт заметно быстрее.

## Управление

- `WASD` / стрелки — идти, `Shift` — бежать (шумно!)
- Мышь — смотреть (после старта кликни по экрану, чтобы захватить курсор; `Esc` — пауза)
- `F` (держать) — изобразить крик без микрофона, `V` (держать) — шёпот
- `M` — звук · `H` — экран управления · `G` — полный экран · `P` — пауза
- ТРУБЫ = крик · ЩИТКИ = шёпот

Голос-кнопки `F/V` работают и при включённом микрофоне — как подстраховка, если он глючит.

## Телефон / планшет

- Тач-режим включается сам: левая половина экрана — джойстик, правая — поворот камеры.
- Кнопки справа: 💥 крик (держать), 🤫 шёпот (держать), 🏃 бег (вкл/выкл).
- По кнопке старта игра сама просит полный экран.
- В меню есть кнопка ⛶ — принудительный полный экран, `M` — звук.

## Запуск

Микрофону нужен безопасный контекст, поэтому лучше через локальный сервер:

```bash
cd docs
python3 -m http.server 8000
```

Открыть http://localhost:8000, выбрать режим и микрофон/клавиатуру.
На GitHub Pages (https) микрофон работает напрямую.

## Без наушников

Звуки игры могут ловиться микрофоном — тогда труба «чинится сама», а Сосед злится. Выходы:

- `M` — выключить игровые звуки (🔇 в правом верхнем углу);
- или приглушить/выключить системный звук на время игры;
- или играть в режиме клавиатуры/тач — там микрофон вообще не используется.

🎧 В мультиплеере играть в наушниках, иначе голос друга будет ловиться твоим микрофоном.

## Файлы

- `index.html` — премиум-версия от первого лица: pointer-lock, руки с гаечным ключом, bloom, вода, мониторы, 5 систем (3 трубы + 2 щитка), ползунок чувствительности микрофона, мультиплеер на 2 игроков, тач-управление (Three.js + Web Audio API + PeerJS).
- `index-fp-v1.bak.html` — архивная 3D-версия от третьего лица.
- `classic-2d.html` — первая 2D-прототип-версия (canvas).
- `models/helmet.glb` — винтажный скафандр на бочке внутри лодки (модель с Sketchfab, сжатая для веба).
- `models/nautilus.glb` — субмарина за иллюминаторами, медленно дрейфует в темноте (модель с Sketchfab, конвертированная из FBX и сжатая).
- `models/decor/` — декор внутри лодки и рыбки за иллюминаторами: консоли, резервуары, стеллаж, капсула, книжный шкаф, кресло, растение; рыбы плавают снаружи (CC0-модели Quaternius).
- Магнитофон с лоу-фай радио (B / кнопка 🎵): ненавязчивая музыка с шумом винила — сгенерирована на лету через Web Audio.
- Баллоны кислорода (+20%) на полу, постеры на стенах, холодильник и табурет, всего 5 рыб за иллюминаторами.
