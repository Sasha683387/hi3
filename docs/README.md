# 40 метров тишины — прототип

Соло-прототип механики «голос-инструмент» из кооп-концепта про тонущую субмарину.
(Вдохновлено формулой BOMBANANA! — кооп с асимметричной информацией, но с другим базовым циклом.)

## Механика

- Труба может заделываться **только голосом**: чем громче — тем быстрее.
- **Крик** чинит быстро (~16% / с) и жжёт кислород в ~10 раз сильнее.
- **Шёпот** чинит медленно (~2.4% / с), кислород почти не тратит.
- Заделка трубы даёт **+30 воздуха** и откачивает 25% воды.
- **Сосед** плывёт на громкий звук: кричи кусками, между криками молчи — тишина отгоняет его.
- Луз: воздух кончился, отсек затопило (вода 100%), Сосед добрался.

## Управление (3D-версия)

- `WASD` / стрелки — ходить по отсеку к лопнувшей трубе
- Голос (микрофон) или `F` (крик) / `S` (шёпот) — ремонт, когда стоишь у трубы
- `M` — вкл/выкл звук · **⛶ кнопка или `F`** — полный экран
- Старая плоская версия так же доступны: `classic-2d.html`

## Запуск

Микрофону нужен безопасный контекст, поэтому лучше через локальный сервер:

```bash
cd docs
python3 -m http.server 8000
```

Открыть http://localhost:8000, нажать «Играть с микрофоном» (или клавишу `1`).

Без микрофона: «Играть с клавиатурой» (`2`), управление — `F` (крик), `S` (шёпот).

## Без наушников

Звуки игры (пищалки, сердцебиение) могут ловиться микрофоном — тогда труба будет «чиниться сама»,
а Сосед злиться без причины. Выходы:

- `M` — выключить игровые звуки (индикатор 🔇 в правом верхнем углу);
- или приглушить/выключить системный звук на время игры;
- или играть в режиме клавиатуры — там микрофон вообще не используется.

🎧 Играть в наушниках, иначе микрофон будет слышать звуки игры.

## Файлы

- `index.html` — 3D-версия одним файлом (Three.js с CDN + Web Audio API).
- `classic-2d.html` — первая 2D-прототип-версия (canvas).
